# Тривога

Монитор воздушной тревоги в Украине для **Windows 7/8/10/11** и **Android 5–16**.
При тревоге голос называет угрозу («Увага! Повітряна тривога! Загроза балістичних ракет!»), потом звучит сирена.
При отбое — «Відбій повітряної тривоги».

- `Trevoga.exe` — программа для Windows (ничего ставить не нужно, нужен .NET Framework 4.x)
- `Trevoga.apk` — приложение для Android
- `server/` — сервер-посредник на Cloudflare (держит токен alerts.in.ua)
- `config.json` — адрес сервера, программы берут его отсюда

## Как это устроено

```
alerts.in.ua  ←(токен)—┐
                        ├─ сервер на Cloudflare ←—  Trevoga.exe / Trevoga.apk
NEPTUN        ←————————┘
```

Сервер берёт данные из двух источников для всех пользователей сразу (alerts.in.ua — раз в 20 с, NEPTUN — раз в 5 с), программы спрашивают сервер раз в 15 с. Задержка с нашей стороны — в среднем ~10 с, максимум ~25 с.

- **alerts.in.ua** — статусы всех областей/районов и типы угроз (балістика, дрони…). Нужен токен, его знает только сервер.
- **NEPTUN** (neptun.in.ua) — официальные тревоги UkraineAlarm по районам. Ключ не нужен.
  Условие их API — видимая ссылка на NEPTUN; она есть в обеих программах.

Программы сверяют источники: **тревога включается, если её показывает хотя бы один** (лучше лишний раз
предупредить, чем пропустить). Если источники расходятся, на карточке написано «підтверджує 1 з 2 джерел».
Типы угроз берутся только из alerts.in.ua.

Пользователи ничего не вводят: выбирают область/район и всё. Если сервер недоступен, программы работают
через ubilling.net.ua — только по областям (при выбранном районе — молчат и показывают «Немає даних по району»).

## Настройка сервера (один раз)

1. **Токен alerts.in.ua.** Подайте заявку: https://alerts.in.ua/api-request (своими словами опишите,
   что это сервер-посредник для приложения оповещения, запросы раз в 20 секунд).

2. **Cloudflare** (бесплатно):
   - зарегистрируйтесь на https://dash.cloudflare.com/sign-up;
   - откройте раздел **Workers & Pages** один раз — Cloudflare создаст вам адрес вида `ваше-имя.workers.dev`;
   - **API-токен**: My Profile → API Tokens → Create Token → шаблон **Edit Cloudflare Workers** → Continue → Create.

3. **GitHub** — в этом репозитории: **Settings → Secrets and variables → Actions → New repository secret**, два секрета:

   | Имя | Что вписать |
   | --- | --- |
   | `ALERTS_TOKEN` | токен alerts.in.ua |
   | `CLOUDFLARE_API_TOKEN` | API-токен Cloudflare |
   
4. **Запуск:** вкладка **Actions → Deploy server (Cloudflare) → Run workflow**.
   Через минуту сервер работает, а его адрес сам запишется в `config.json`.
   Проверка: откройте `адрес/health` — должно быть `"ok": true`.

5. **Пересоберите программы** (`build.bat` и `android/build_apk.sh`), чтобы адрес сервера вшился в них.
   Если сделать репозиторий публичным, уже установленные программы подхватят новый адрес сами (в течение 6 часов).

Account ID Cloudflare уже вписан в `server/wrangler.toml`.

Поменять токен: обновите секрет `ALERTS_TOKEN` и снова запустите workflow.

## Сколько это стоит

Каждое устройство спрашивает сервер раз в 15 секунд — это ~5 800 запросов в сутки.

| План Cloudflare | Запросов | Хватит примерно на |
| --- | --- | --- |
| Free | 100 000 в сутки | ~17 устройств |
| Paid, $5/мес | 10 млн в месяц, дальше $0.30 за млн | ~55 устройств за $5; 1000 устройств ≈ $55/мес |

Если лимит Free закончится, сервер до полуночи UTC перестанет отвечать, и программы автоматически перейдут
на ubilling.net.ua (тревоги по областям продолжат работать).

## Windows

Распакуйте архив в постоянную папку (например `C:\Trevoga`), запустите `Trevoga.exe`, выберите область и район.
«Запускати разом з Windows» кладёт ярлык в папку «Автозагрузка» — программа стартует свёрнутой к часам.
Если программа уже запущена, повторный запуск просто откроет её окно.
Крестик прячет программу к часам, выход — правой кнопкой по значку.

- Свои звуки: положите рядом с программой `alarm.mp3`/`alarm.wav`, `clear.mp3`/`clear.wav`, `ballistic.mp3`/`ballistic.wav`.
- Настройки хранятся в `trevoga.ini` рядом с программой.
- Если на Windows 7 «Немає зв'язку»: запустите `win7_tls12.reg`, перезагрузите компьютер; при необходимости поставьте .NET Framework 4.8.
- Сборка: `build.bat` (встроенный компилятор Windows, ничего ставить не нужно).

## Android

Откройте `Trevoga.apk` на телефоне, разрешите установку из этого источника.

- Обязательно разрешите работу без ограничений батареи (приложение спросит само). На Xiaomi/Huawei/Samsung дополнительно включите автозапуск.
- Сирена идёт через громкость будильника — слышно и в беззвучном режиме.
- Свои звуки — в разделе «Сповіщення».
- Сборка: `android/build_apk.sh` (Linux, без Android Studio).

## Голос

Голоса синтезированы открытой моделью ukrainian-tts (github.com/robinhad/ukrainian-tts, MIT), файлы — в папке `voice/`.
