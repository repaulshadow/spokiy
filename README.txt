ТРЕВОГА — монитор воздушной тревоги для Windows 7 / 8 / 10 / 11
================================================================

ЗАПУСК
1. Распакуйте папку куда угодно (например C:\Trevoga).
2. Запустите Trevoga.exe, выберите свою область.
3. Поставьте галочку "Запускать вместе с Windows" — программа будет стартовать свёрнутой к часам.

При начале тревоги играет сирена и всплывает уведомление, при отбое — сигнал отбоя.
Кнопки "Тест тревоги" / "Тест отбоя" — проверить звук.

РАЙОН
Во втором списке можно выбрать конкретный район. Сигнал сработает, если тревога
объявлена в этом районе ИЛИ во всей области.
Районы работают только с токеном alerts.in.ua (см. ниже). Без токена программа
следит за всей областью и пишет об этом под статусом.

ТИП УГРОЗЫ (с токеном alerts.in.ua)
Во время тревоги под статусом видно, что объявлено: Балістика, Крилаті ракети, Дрони,
КАБи, Тактична/Стратегічна авіація, Зліт МіГ-31К, Робота ППО, Артобстріл и т.д.
При появлении БАЛІСТИКИ звучит отдельный срочный сигнал (свой: ballistic.wav / ballistic.mp3).
Если во время тревоги добавилась новая угроза — всплывает уведомление.

ГОЛОС
Перед сиреной голос объявляет, что происходит: «Увага! Повітряна тривога! Загроза
балістичних ракет! Пройдіть в укриття!», затем сирена. При отбое — «Відбій повітряної
тривоги». Голос: жіночий (Тетяна), чоловічий (Микита) или без голоса — выбирается в программе.
Голоса синтезированы моделью ukrainian-tts (github.com/robinhad/ukrainian-tts, MIT), файлы — в папке voice/.

СВОИ ЗВУКИ
Положите рядом с Trevoga.exe файлы alarm.wav или alarm.mp3 (тревога)
и clear.wav или clear.mp3 (отбой).

ИСТОЧНИК ДАННЫХ
По умолчанию — ubilling.net.ua (без регистрации).
Надёжнее — alerts.in.ua: запросите бесплатный токен на https://alerts.in.ua/api-request
и впишите его в trevoga.ini в строку token=...  Перезапустите программу.
С токеном доступны районы, Крым и опция partial=1 (тревога только в части района/области).

ЕСЛИ НА WINDOWS 7 НЕ ЗАПУСКАЕТСЯ ИЛИ "НЕТ СВЯЗИ"
- Нужен .NET Framework 4.x. Лучше поставить .NET Framework 4.8 (бесплатно, с сайта Microsoft).
- Нужен Windows 7 SP1 со свежими обновлениями (корневые сертификаты).
- Дважды кликните win7_tls12.reg (включает TLS 1.2), перезагрузите компьютер.

САМОСТОЯТЕЛЬНАЯ СБОРКА
Trevoga.cs — исходный код. build.bat собирает Trevoga.exe встроенным компилятором Windows,
ничего устанавливать не нужно.

ВАЖНО: это вспомогательный сигнал. Не полагайтесь только на него —
держите включённым и официальный застосунок "Повітряна тривога" на телефоне.
